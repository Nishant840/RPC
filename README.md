# RPC

A small repository created while learning **Remote Procedure Call (RPC)** concepts and exploring different RPC technologies.

## What I Learned

I explored RPC progressively:

1.  **JSON-RPC** — Understanding the basic RPC request/response model using JSON.
    
2.  **Protocol Buffers (Protobuf)** — Learning how to define structured messages and services using `.proto` files.
    
3.  **gRPC** — Building RPC services using Protobuf and gRPC.
    

## Topics Covered

-   RPC fundamentals
    
-   JSON-RPC
    
-   Protocol Buffers
    
-   `.proto` files
    
-   Service and message definitions
    
-   gRPC
    
-   gRPC code generation
